# Affordable Prosthetic Arm — Version 3

I'm documenting the design, electronics, programming, testing, and improvements I'm making to my affordable prosthetic arm.

## About the Project

This project is focused on creating an affordable prosthetic arm using accessible components and 3D-printed parts.

## Project Updates

I'll use this website to document my progress, including:

- Mechanical design
- 3D printing
- Servo control
- Sensors
- Electronics
- Raspberry Pi programming
- Testing and improvements
